Search Help

        
      

      

        
Terms combine with AND by default.

        
Spaces and underscores match each other, so use #tag_with_spaces for a multi-word tag.

        

          
#tag
Match an assigned tag exactly.

          
[comment text]
Match text in a comment.

          
'path text'
Match text in the media path.

          
!#tag, ![comment text], !'path text'
Exclude matching tags, comments, or paths.

          
+ or spaces
Match all terms (AND).

          
|
Match either term (OR).

          
(...)
Group terms. Negation, AND, then OR determine precedence.

          
plain text
Match text in the title or path.

        

        
Example: (#tag1 | #tag2) + ![draft] + !'archive'
